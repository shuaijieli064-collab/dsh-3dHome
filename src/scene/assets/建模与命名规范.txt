小拾 · Blender 手建 GLB 规范（characterModel.js 配套）
=================================================

目标：在 Blender 里按「角色三视图（正面_侧面_背面）.png」建模，导出 GLB，
用本仓库的极简解析器加载，尽量 100% 还原设定图，同时接住现有动画系统。

────────────────────────────────────────
0. 启用方式
────────────────────────────────────────
模型化是小拾的唯一路线（程序化拼装版已删除）。

1) 把导出的文件命名为 xiaoshi.glb，覆盖本目录（src/scene/assets/）里的同名文件。
   若想保留旧模型做对比，可取别的文件名，再把
   src/scene/characterModel.js 顶部的 CHARACTER_MODEL_URL 改成新路径。
2) 重新启动 node server.mjs（或 npm run demo）。
3) 加载失败会重试 2 次，仍失败则控制台打 console.error 并让展示台空着
   （没有程序化兜底了）。台子空 = 模型没加载上，看第一条 error 定位原因。

────────────────────────────────────────
1. 单位与朝向（解析器会按高度归一化，但请尽量对齐，便于表情贴图对位）
────────────────────────────────────────
- 脚底放在 y = 0，整体高度约 1.10（与程序化小拾一致）。
- 面向 +Z（正脸朝镜头）。右手为 +X。
- 头部中心约在 y = 0.78、正面 z ≈ +0.30，半径约 0.30。
  （这决定 Canvas 表情贴图的贴合位置，不对齐就脸歪。）

────────────────────────────────────────
2. 拆分独立部件（动画全靠「旋转/缩放命名节点」，不要用骨骼蒙皮！）
────────────────────────────────────────
本方案用「空物体 / 父子层级」做枢轴，不依赖 Armature/Skin。
原因：极简解析器不处理蒙皮，且现有 tick() 只旋转/缩放约 5 个命名部件，
刚性拆分更简单、可控、零依赖。

必须给下列对象取【精确】名字（节点名，不是材质名）：
  Head        头部整体（含脸）。表情贴图会贴到它前方。
  Dress       裙身（用来做呼吸缩放）。导出时该节点 scale 设为 1。
  Ahoge       呆毛（弹簧摆动）。把物体原点设在呆毛根部当枢轴。
  Tail        鲸尾（慢摆）。原点设在尾根。
  Fin_L       左侧鱼鳍耳翼      Fin_R  右侧鱼鳍耳翼（下垂+微摆）
其余部件（头发、围裙、蝴蝶结、手臂、腿、鞋…）自由命名，按普通父子层级摆放。

提示：在 Blender 里用 Ctrl+P → Object 做父子，或建 Empty 当枢轴，
把网格挂到对应节点下；旋转动画是在这些【节点】上叠加，作者原摆姿会被保留。

────────────────────────────────────────
3. 材质命名（被换色板 CHAR_PALETTES 接管；不用贴图，纯色即可）
────────────────────────────────────────
给材质取下列名字之一，解析器会用调色板覆盖颜色；没列出的保持 GLB 内置色。
  mat_hair        → hair（深蓝主发）
  mat_hair_tip    → tip （发梢天蓝）
  mat_dress       → dress（藏青裙）
  mat_sleeve      → sleeve（袖/上身深色）
  mat_fin         → fin （鳍/尾深色边）
  mat_fin_light   → finLight（鳍/尾浅色膜）
  mat_whale       → whale（围裙鲸鱼色，字符串如 '#8fb6e2'）
  mat_skin        → skin（肤色 0xffeadf）
  mat_lace        → lace（蕾丝白 0xfbf7ef）
  mat_gold        → gold（金饰 0xd0a04b）

注意：脸、鲸鱼围裙绣样、名牌等细节【不要】建模进 GLB——
它们由仓库的 Canvas 贴图系统（characterTextures.js）在代码里生成并叠加，
以保证线稿级质感和换色一致。模型只负责形状 + 纯色。

────────────────────────────────────────
4. 导出设置（File → Export → glTF 2.0）
────────────────────────────────────────
- 格式 GLB（单文件，贴图内嵌）。
- +Y Up。
- Geometry → Apply Modifiers 勾选。
- 不要勾选 Draco / Meshopt 压缩（解析器不支持）。
- 不要导出 KTX2 / 外部贴图（我们不用模型贴图）。
- 形变/骨骼动画都不需要导出（动画由 tick() 在命名节点上实时驱动）。
- 勾选 Include → Custom Properties（可选，便于扩展）。

────────────────────────────────────────
5. 可选：反向壳描边
────────────────────────────────────────
想要日系描边，在 characterModel.js 顶部把
  const OUTLINE_NODES = [];
改成节点名数组，例如 ['Head','Hair','Dress']。
前提：这些网格的几何体原点必须在其自身中心，否则描边会错位。
不确定就先留空（关），用 toon 着色也够。

────────────────────────────────────────
6. 校验清单
────────────────────────────────────────
□ 三视图轮廓对齐（正面/侧面/背面）。
□ 命名节点：Head / Dress / Ahoge / Tail / Fin_L / Fin_R 齐全。
□ 材质名命中上表（或接受内置色）。
□ 无压缩、无外部贴图、GLB 单文件。
□ 头部 y≈0.78、正面 z≈+0.30，表情贴图对位。
□ 启用 URL 后浏览器控制台出现「已加载模型化小拾」且无报错。
